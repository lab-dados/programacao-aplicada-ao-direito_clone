O que é o Pyodide?

É o Python adaptado para rodar dentro do navegador, em WebAssembly. Normalmente, uma página só mostra arquivos, e o Python roda no seu computador ou num servidor. Com o Pyodide, quem roda o Python é o próprio navegador. Quando você abre esta página:

  1. o navegador baixa o Python, o pandas e o matplotlib (na primeira vez, leva alguns segundos);
  2. lê o analise_2.py que está ao lado desta página;
  3. chama as funções dele com a base que você escolher, e mostra o resultado aqui.

Por isso a página funciona no GitHub Pages, que só guarda arquivos, e o CSV que você envia não sai do seu computador.
